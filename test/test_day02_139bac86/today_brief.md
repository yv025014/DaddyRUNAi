# 測試簡報 — 第 2 天

**日期**：2026-05-24
**格式**：tech（7 頁）
**故事標題**：API 是什麼？
**支柱**：tech — API 是什麼？
**技術概念**：API
**生活事件**：餐廳點餐，櫃台傳話

## 故事場景

**P1** [narrator / neutral]
API 是什麼？

**P2** [anna / curious]
把拔，為什麼我不能直接去廚房拿蛋糕？

**P3** [chris / proud]
因為餐廳有規則。你跟櫃台說，櫃台再去跟廚房說，廚師才會把菜送出來給你。

**P4** [anna / smirk]
所以櫃台是幫我傳話的人？

**P5** [chris / normal]
對。API 就像系統之間的櫃台，負責照規則傳話，幫忙交換資料。

**P6** [anna / smirk]
那我叫把拔問媽咪可不可以吃餅乾，把拔也是櫃台嗎？

**P7** [narrator / neutral]
API 不是魔法，是系統之間照規則傳話的櫃台。傳給那個一直聽不懂 API 的人。

Anna這次對API的理解，讓把拔差點接不上話啦！😅 她說把拔幫她問媽咪能不能吃餅乾，把拔就是那個「櫃台」，這個比喻真的是太精準又太可愛了！你們第一次搞懂API是什麼，是聽誰怎麼解釋的呢？來留言跟把拔分享一下吧！
