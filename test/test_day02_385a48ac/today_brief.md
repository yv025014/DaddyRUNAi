## 故事場景

**P1** [anna / curious]
把拔，為什麼我不能自己跑進廚房拿蛋糕？

**P2** [chris / proud]
因為廚房有規則。妳要先跟服務生點餐，他再幫妳進去拿出來。

**P3** [anna / smirk]
所以服務生是幫我和廚房傳話的中間人？

**P4** [chris / normal]
對。API 就像服務生，負責在系統之間照規則傳遞訊息。

**P5** [anna / smirk]
那我想吃點心時把拔幫我問媽咪，把拔也是 API 嗎？

**P6** [narrator / neutral]
API 就像系統傳話的服務生。傳給一直聽不懂 API 的人。
