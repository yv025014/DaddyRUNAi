**技術概念**：API
**生活事件**：餐廳點餐

## 故事場景

**P1** [anna / curious]
把拔，為什麼我不能直接去廚房拿蛋糕？

**P2** [chris / proud]
因為餐廳有規則。你跟櫃台說，櫃台再去跟廚房說，才不會亂掉。

**P3** [anna / smirk]
所以櫃台是幫我傳話的人？

**P4** [chris / normal]
對。API 就像系統之間的櫃台，負責照規則傳話。

**P5** [anna / smirk]
那我叫把拔問媽咪可不可以吃餅乾，把拔也是櫃台嗎？

**P6** [narrator / neutral]
API 就是系統間傳話的櫃台。Tag 那個 API 霧煞煞的朋友！
